Visual system — Wallet Control
logo · typography · color · buttons · icons
Logo
A closed bracket around a single point. The bracket is containment — a boundary the agent cannot cross; the point is the transaction held inside it. It reads as a card edge, a shield, and a pair of brackets from code, which is the three things this product is at once. Geometric, no gradient, no mascot: a payments mark has to survive being embossed, faxed, and printed at 8mm.

Clear space
Half the mark's height on all four sides. Nothing enters it, including the wordmark's own descenders.
Minimum size
Mark 16px on screen, 8mm in print. Below that the bracket gaps close — use the solid variant.
Never
No rotation, no gradient fill, no outline on the dot, no second accent colour, no drop shadow, never re-coloured to red.
Accent meaning
The dot is green when a leash is active, grey when none is, red only in the frozen state — the logo is itself a status indicator.
Typography — Inter
One family, four weights, with IBM Plex Mono reserved for machine-generated identifiers. Inter's tall x-height and unambiguous 1/l/I and 0/O keep card digits and amounts legible at 11px on a phone in daylight. The tone is deliberately plain: this interface asks people to authorise money, and personality in the typeface would read as sales.

Color palette
Three hues carry the whole decision model and nothing else may use them: green allowed, red stopped, violet your turn. Because the palette is semantic rather than decorative, a user learns the system by colour in a single session. Warm neutrals do ninety percent of the work, and a saturated fill appears on at most one element per screen.

Colour never carries meaning alone — every green, red, and violet state is accompanied by a word and a shape, so the system works for the eight percent of men with colour-vision deficiency and in any monochrome print of the audit trail.
Buttons
Five variants across six states. Fill weight equals consequence: solid dark for navigation, solid green only for an approval that moves money, outline for the equally-valid refusal, outlined red for destruction. Minimum target 48px on any decision action, and a destructive button never sits adjacent to the primary one.

Focus
3px violet ring, 2px offset, never removed — visible on white, dark, and green grounds.
Separation
Destructive actions sit below a divider with 12px clearance, or move into a sheet.
Icon set
Twenty icons on a 24px grid with a 2px stroke, square caps, and 3px corner radius — drawn from the same geometry as the logo so the bracket motif recurs throughout the product. Banking conventions are kept intact (a card is a card, a shield is a shield); only the leash mark is invented, because nothing standard means “a boundary an agent operates inside”.

Rules
No filled shapes except the decision dots. No perspective, no rounded “friendly” terminals, no icon used decoratively beside a heading. Every icon in the product either labels a destination or precedes an action.
